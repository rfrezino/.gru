# Installation

Requires Delphi Berlin or newer. Open `Packages/<DelphiVersion>/RFindUnit.dproj` (DelphiSeattle, DelphiBerlin, DelphiTokyo), right-click the project and Install. Alternatively install via the Delphinus package manager (`Delphinus.Install.json`, `Delphinus.Info.json`). Part of [Overview](/overview.md).

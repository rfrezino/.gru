TypeScript single-file macros in `ultimaonline/` for ClassicUO Web Scripting (global `client`, `Item`): `pickup-gold.ts` (scan within 2 tiles for gold id 0xEED, pick up and drop on self), `tamming.ts` (approach, tame, handle release gump; gump ids marked "verify per shard"), `tammer-fight.ts`, `attak-all.ts`, `mount-dismount.ts`, `remove-trap-train.ts`.

In `windows/`: `generalCommands.ps1` (env vars, `o`/`of` open helpers), `shortcutsToDirs.ps1` (`rd-*` functions to jump to project dirs), `buildServiceHelper.ps1` (grep Cake build tasks), `migrateDelphiRepo.ps1` (merge Delphi repos into one), `remove_grants.py`. Root `gitCommands.ps1` holds git shortcuts.

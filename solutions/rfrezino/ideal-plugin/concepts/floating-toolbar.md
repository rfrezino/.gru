---
type: "Class"
title: "TestVisualizationProvide"
description: "Floating editor toolbar provider that shows the test action group."
---
`TestVisualizationProvide` extends `AbstractFloatingToolbarProvider` with group `fresh.com.freshbooks.fresh.TestVisualizationGroup` and is auto-hideable. The popup group in plugin.xml holds the [test actions](/concepts/test-actions.md).

Note: plugin.xml references the class as `TestVisualizationProvide`, matching the class name (the file is named TestVisualizationProvider.kt).
